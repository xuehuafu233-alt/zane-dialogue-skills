# Zane Dialogue Skills

Reusable Skills for problem definition, AI collaboration, and human agency in the AI era.

## Included

- `zane-question-intent-translator`: translate natural-language questions into real intent, the current decision, and a copyable AI prompt.
- `zane-agent-identity-card-builder`: define identity, judgment, memory, correction, and relationship boundaries for an AI collaborator.
- `zane-self-insight`: separate facts, experiences, self-narratives, external scripts, and testable patterns.

Experts and other Skills are optional downstream resources, not prerequisites.

## Install

```bash
npx -y skills add xuehuafu233-alt/zane-dialogue-skills -g --all
```
