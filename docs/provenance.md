# Provenance

The dialogue collection is based on repeated work around problem definition, question translation, AI identity cards, self-insight, and the difference between truthful judgment and premature risk auditing.

`zane-question-intent-translator` grew from repeated cases where a user's wording, actual decision, and desired progress were different. It turns that gap into an executable question without deleting the user's stance.

`zane-self-insight` is generalized from the public self-insight method and contains no personal memories, private paths, or environment-specific storage rules.

The collection may be informed by other public methods, but does not repackage third-party upstream Skill files as Zane originals.
