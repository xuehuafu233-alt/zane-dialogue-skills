# Provenance

The dialogue collection is based on repeated work around problem definition, question translation, AI identity cards, self-insight, and the difference between truthful judgment and premature risk auditing.

`zane-question-intent-translator` is not a requirement to use experts or a copy of an expert-chat workflow. It treats expert consultation as an optional downstream action.

`zane-self-insight` is generalized from the public self-insight method and contains no personal memories, private paths, or workbench routing.

The collection may be informed by other public methods, but does not repackage third-party upstream Skill files as Zane originals.
